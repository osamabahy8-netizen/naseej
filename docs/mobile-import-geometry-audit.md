# اختبار استيراد المرحلة الثانية على الموبايل ومراجعة الأبعاد

## ما الذي أضيف؟
- فحص ملف JSON قبل استبدال المشهد الحالي.
- رفض الوحدات غير المدعومة بدل افتراض أنها مليمتر.
- رفض القطاع أو سُمك اللوح المفقود بدل اختراع مقاس افتراضي.
- الاحتفاظ بأبعاد وموقع ودوران المصدر داخل بيانات كل قطعة.
- لوحة مراجعة قابلة للفتح تعرض تصنيف الاتجاه المبدئي، أبعاد المعاينة، الموضع والدوران الأصليين والكمية.
- تحسين ترتيب مساحة الرسم والخصائص وأزرار التحكم في وضع الهاتف الرأسي.

## نتائج تحقق بيانات النماذج
تم فحص أمثلة المرحلة الثانية العشرة الموجودة في الحزمة:
- 10 ملفات JSON.
- 207 قطعة.
- 74 قطاعًا مصنفًا رأسيًا مبدئيًا.
- 84 قطاعًا طوليًا مبدئيًا.
- 49 لوحًا أو قطعة صاج.
- لم تظهر أخطاء في وجود الأبعاد والتحويلات الأساسية أثناء الفحص.

## حدود الاختبار
تصنيف الاتجاه ما زال مبدئيًا ويستند إلى كود/اسم القطعة مع دوران المصدر؛ لذلك يجب مراجعة كل قطعة في المجسم والمساقط قبل اعتماد اتجاه القص أو التجميع. فحص البيانات لا يثبت صحة التصميم الإنشائي أو الوصلات أو الأحمال أو السماحات.

لم يتم تنفيذ اختبار بصري فعلي على هاتف Android أو متصفح حي ضمن هذه الدفعة. التعديلات تتضمن قواعد CSS مخصصة للموبايل، ويجب إجراء اختبار الجهاز الفعلي بعد نشرها. لا تعتبر هذه الملفات رسومات تصنيع معتمدة حتى تتم مراجعة النموذج ومقاساته واتجاهاته عمليًا.
