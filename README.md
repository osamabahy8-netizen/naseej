# نسيج

منظومة معرفية تفاعلية تهدف إلى ربط الأفكار والمعلومات والمشروعات في شبكة مترابطة، وتحويل المعرفة إلى ابتكار وتصميم وتطوير وتصنيع.

## النسخة الأولى

تعمل الواجهة مباشرة في المتصفح دون تثبيت أو خدمات خارجية.

### الملفات
- `index.html` — هيكل الواجهة العربية.
- `styles.css` — تصميم متجاوب للكمبيوتر والهاتف.
- `app.js` — إدارة الأفكار والمشروعات والروابط وحفظ البيانات.

### الوظائف الحالية
- إضافة فكرة أو مشروع وتعديلهما وحذفهما.
- ربط عنصرين داخل خريطة تفاعلية.
- عرض تفاصيل العنصر المحدد.
- حفظ البيانات تلقائيًا في المتصفح باستخدام Local Storage.
- تصدير نسخة احتياطية بصيغة JSON واستيرادها.

## التشغيل
افتح `index.html` في متصفح حديث. لا تحتاج النسخة الحالية إلى خادم أو مكتبات خارجية.

> ملاحظة: البيانات محفوظة محليًا في المتصفح والجهاز الذي تستخدمه. استخدم تصدير النسخة الاحتياطية لنقلها أو الاحتفاظ بنسخة منها.
