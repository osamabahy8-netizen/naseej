# نسيج

منظومة معرفية تفاعلية تهدف إلى ربط الأفكار والمعلومات والمشروعات في شبكة مترابطة، وتحويل المعرفة إلى ابتكار وتصميم وتطوير وتصنيع.

## فكرة المشروع

نسيج مساحة عمل مرئية لتنظيم الأفكار والمشروعات، وربطها بعلاقات تساعد على فهم الصورة الكاملة ومتابعة تطور العمل.

## الملفات الأساسية

- `index.html` — هيكل الواجهة العربية.
- `styles.css` — التصميم المتجاوب للهاتف والكمبيوتر.
- `app.js` — إدارة الأفكار والمشروعات والمجموعات والروابط والحفظ.
- `manifest.json` — تعريف التطبيق القابل للتثبيت.
- `service-worker.js` — تخزين ملفات الواجهة الأساسية للعمل دون اتصال.
- `icons/naseej.svg` — أيقونة التطبيق.

## الوظائف المنفذة

### إدارة الأفكار والمشروعات
- إضافة فكرة أو مشروع.
- تعديل البيانات وحذف العناصر.
- عرض تفاصيل العنصر المحدد.
- تحديد نوع العنصر ووصفه.

### خريطة العلاقات التفاعلية
- عرض الأفكار والمشروعات على خريطة مرئية.
- ربط عنصرين بخط علاقة.
- إظهار العلاقات بين العناصر.
- تحريك العناصر بالسحب والإفلات على الهاتف والكمبيوتر.
- تحديث خطوط الربط أثناء تحريك العناصر.
- حفظ مواقع العناصر بعد انتهاء السحب.

### المجموعات
- إنشاء مجموعات لتنظيم الأفكار والمشروعات.
- إسناد العنصر إلى مجموعة من نموذج الإضافة أو التعديل.
- عرض كل المجموعات أو تصفية الخريطة لعرض مجموعة واحدة.
- إظهار عدد العناصر بجوار اسم كل مجموعة.
- إظهار العلاقات التي تربط العناصر الظاهرة في العرض الحالي.
- اختيار المجموعة المعروضة تلقائيًا عند إضافة عنصر جديد أثناء تصفيتها.
- الاحتفاظ بالعناصر القديمة التي لم تُسند إلى مجموعة، مع استمرار ظهورها في عرض كل المجموعات.

### حفظ البيانات والنسخ الاحتياطي
- حفظ تلقائي محلي في المتصفح باستخدام Local Storage.
- تصدير نسخة احتياطية بصيغة JSON واستيرادها.
- دعم البيانات القديمة التي أُنشئت قبل إضافة المجموعات.

### التثبيت والعمل دون اتصال
- التطبيق قابل للتثبيت من المتصفح كتطبيق ويب.
- تخزين ملفات الواجهة الأساسية بعد أول زيارة ناجحة.
- تسجيل عامل الخدمة على اتصال آمن HTTPS.

## التشغيل

افتح الموقع المنشور أو ملف `index.html` في متصفح حديث. لا تحتاج الواجهة الحالية إلى خادم أو مكتبات خارجية.

## ملاحظات مهمة

- بيانات الأفكار والمشروعات والمجموعات محفوظة محليًا في المتصفح وعلى الجهاز نفسه.
- نشر ملفات المشروع على GitHub Pages لا يعني أن البيانات تتزامن تلقائيًا بين الأجهزة.
- وضع العمل دون اتصال يحفظ ملفات التطبيق، لكنه لا ينقل بيانات المستخدم تلقائيًا بين المتصفحات أو الأجهزة.
- استخدم تصدير النسخة الاحتياطية للاحتفاظ بنسخة من بياناتك أو نقلها يدويًا.
- إدارة أسماء المجموعات وحذفها، والمزامنة السحابية بين الأجهزة، ليست ضمن الوظائف الموثقة كمنفذة حاليًا.



## مكتبة تجهيز المحلات والتصنيع
يحتوي استوديو التصميم على كتالوج قابل للبحث والتصفية حسب النشاط، ويضم نماذج مرجعية في:
- محلات الملابس والأزياء: استاندات تعليق، وحدات حائط، جزر عرض، ترابيزات، أحذية، كاشير، غرف قياس ومنصات مانيكان.
- التجزئة والسوبر ماركت: رفوف جزيرة وحائط، كاشير، عرض خضار وفاكهة، وفاترينات.
- الكافيهات والمطاعم: كاونترات، وحدات خلفية، قواعد ترابيزات، فواصل، ترابيزات تجهيز ستانلس، أحواض، أرفف، عربات وحوامل شفاط.
- المولات والأكشاك: أكشاك قابلة للفك، وحدات موسمية، كاونترات فود كورت ومقاعد انتظار.
- الحديد والمعادن: سلالم ودرابزين، مظلات، برجولات، أرفف أحمال وعربات.
- الديكور: فواصل ليزر، هياكل إضاءة ولافتات وأحواض زرع.

كل بطاقة تعرض مقاسات مرجعية وخامات واستخدامات، ويمكن إضافتها كمشروع إلى خريطة نسيج. المقاسات استرشادية وليست مواصفات تنفيذ أو اعتماد أحمال؛ يجب مراجعة الموقع والاشتراطات والكود والحسابات الإنشائية والصحية قبل التصنيع.

## استوديو الاستاندات والمجسمات
- تعديل العرض والارتفاع والعمق وعدد الرفوف والخامة واللون.
- إرفاق صورة مرجعية مضغوطة وحفظها مع التصميم.
- حفظ أكثر من تصميم وفتح التصميمات المحفوظة.
- معاينة مجسمة مبدئية، وتفكيك بصري لمكونات الاستاند وإعادة تجميعها.
- اختيار القاعدة والقوائم والإطار والعارضة والرفوف وتحرير اسم كل قطعة وخامتها وملاحظاتها.
- تصدير صورة PNG وملف OBJ يحتوي على مجسمات منفصلة للقطع، ويمكن استيراد OBJ في برامج نمذجة ثلاثية الأبعاد مثل Blender لمزيد من التعديل.

ملاحظة: المعاينة الحالية داخل المتصفح رسم منظور تفاعلي مبسط وليست محرك CAD أو محاكاة إنشائية. ملف OBJ نموذج هندسي مبدئي، ولا يتضمن حتى الآن تفاصيل اللحامات أو البراغي أو الخلوصات أو تحليل الأحمال. يلزم تدقيق هندسي قبل التصنيع.
